# Demo Product

This project is a demo **ASP.NET Core MVC** application designed with a clean and easy-to-use user interface.  
It was originally built as a layered architecture project, and later enhanced with **Identity integration** for user management.  

## Features
- User login and registration (Identity integration with `AppUser` and `AppRole`)  
- Category and product management  
- Validation with **FluentValidation**  
- Layered architecture (EntityLayer, DataAccessLayer, BusinessLayer)  
- Simple and intuitive UI design for better user experience  

## Technologies
- C# / .NET Core MVC  
- Entity Framework Core  
- Microsoft Identity  
- FluentValidation  

## Purpose
This project was developed for learning and practice purposes.  
It demonstrates the fundamentals of **N-tier architecture, authentication, and database operations** in .NET Core MVC.
